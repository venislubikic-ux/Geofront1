# GeoFront v2.0 — онлайн-версия

## Что внутри
- `index.html` — сама игра (работает и просто как файл, но тогда только офлайн).
- `netlify/functions/api.mjs` — сервер онлайна: аккаунты, комнаты, чат, лидерборд.
- `netlify.toml`, `package.json` — настройки для Netlify.

## Как залить на Netlify (чтобы заработал онлайн)
Важно: перетаскивание папки в Netlify Drop функции НЕ запускает. Нужен один из двух способов.

### Способ 1 — через GitHub (проще всего)
1. Создай репозиторий на GitHub и загрузи туда всё содержимое этой папки.
2. На app.netlify.com: **Add new site → Import an existing project → GitHub**, выбери репозиторий.
3. Build command оставь пустым, Publish directory: `.` → **Deploy**.
4. Готово: открой адрес сайта, зарегистрируйся и создай комнату.

### Способ 2 — через Netlify CLI
```
npm install -g netlify-cli
cd geofront-online
npm install
netlify login
netlify deploy --prod
```

Хранилище (Netlify Blobs) включается само, ничего настраивать не надо.
По желанию в Site settings → Environment variables можно добавить `GF_SECRET` (любая длинная случайная строка) для подписи токенов входа.

## Лимиты бесплатного Netlify
Онлайн работает через опрос сервера: каждый игрок в комнате делает запрос раз в 1,2–2,5 секунды (если вкладка свёрнута, раз в 6 секунд).
Для друзей и небольших комнат бесплатного плана хватит, но при большом количестве игроков лимит запросов к функциям может закончиться. Расход видно в панели Netlify → Usage.

## Что синхронизируется онлайн
Территории (закраска любым инструментом), отмена/повтор, смена сценария, загрузка карты, чат.
Метки, постройки и бригады пока остаются у каждого свои.
